# SiboMate website

This repository is the canonical static site for [sibomate.me](https://sibomate.me/). The site is intentionally dependency-light: the HTML, CSS, JavaScript, and image assets are served directly from the `main` branch.

Keep product claims aligned with the current app and privacy policy. Preserve the App Store link, published prices, contact address, accessibility text, and content security policy when refreshing visuals or copy. Review changes locally before the repository owner pushes or deploys them.
